# Random Picker

Невеликий вебзастосунок українською мовою для випадкового вибору одного варіанта зі списку. Працює у браузері без сервера, інтернету, облікового запису та встановлення бібліотек.

## Локальний запуск

1. Відкрийте папку `Random-Picker` у Провіднику.
2. Двічі клацніть файл `index.html` — він відкриється у вашому браузері.
3. Введіть варіанти у велике поле, кожен з нового рядка, і натисніть **«Додати варіанти»**.
4. Натисніть **«Випадковий вибір»**. Щоб скопіювати результат, скористайтеся кнопкою під ним.

Можна видаляти окремі варіанти, очищати весь список і очищати історію. Щоб додати введені рядки з клавіатури, натисніть `Ctrl + Enter` (на Mac — `⌘ + Enter`).

У картці вибору є перемикач режимів. У режимі **«Колесо фортуни»** сектори автоматично відповідають поточному списку; під час обертання список тимчасово заблокований, а переможець після зупинки додається до тієї ж історії.

## PWA на iPhone

Щоб установити застосунок на iPhone, сайт має бути відкритий через HTTPS (наприклад, після окремого розміщення на GitHub Pages). У Safari відкрийте сайт, натисніть **Поділитися → На початковий екран**, за потреби увімкніть відкриття як вебзастосунку та натисніть **Додати**. Після першого успішного завантаження файли застосунку кешуються й доступні офлайн.

Service Worker потребує HTTPS або середовища розробки, яке браузер вважає безпечним. Відкриття `index.html` подвійним клацанням працює для звичайного використання, але не вмикає офлайн-кеш чи встановлення як PWA.

Список та історія зберігаються в `localStorage` цього браузера. Дані залишаються після перезапуску; очищення даних Safari або сайту видалить їх.

Кешем володіє лише застосунок із префіксом `random-picker-`. Після зміни файлів застосунку збільште версію `CACHE_NAME` у `sw.js` (наприклад, з `v1` на `v2`), щоб клієнти завантажили оновлений набір файлів.

Шляхи в маніфесті, HTML та Service Worker відносні до каталогу проєкту. Це дає змогу розмістити його у кореневому домені або підкаталозі GitHub Pages.

## Файли

- `index.html` — структура сторінки.
- `style.css` — оформлення та анімації.
- `script.js` — логіка списку, вибору, колеса, копіювання, історії та збереження.
- `manifest.webmanifest` — назва, режим відображення, кольори та іконки PWA.
- `sw.js` — кеш файлів для роботи офлайн.
- `icons/` — іконки застосунку розміром 180, 192 та 512 пікселів.
